      How to get a key for free

      1. Ask JB (he has Google Cloud access) for a Google Maps Platform API key, or create one at console.cloud.google.com.
      2. Enable two APIs on it: Maps JavaScript API and Places API (New).
      3. Under key restrictions, allow only those two APIs, and add the tool's web address as an allowed website.
      4. In Quotas, cap Places Text Search at 300 a day and Place Details at 30 a day. That keeps every month inside the free allowance.
      5. Paste the key here, or into the DEFAULT_KEY line at the top of the file so the shared link works for everyone.
